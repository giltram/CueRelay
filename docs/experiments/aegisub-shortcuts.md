# Aegisub 风格打轴快捷键

2026-10-23，仅调整键盘映射与区间播放底层操作。按钮、布局、样式、文案、Tooltip 和原有快捷键提示保持不变。

- G / Enter（含数字键盘 Enter）调用原有 `applyTimes`；S / Space 单次播放当前时间草稿区间。
- Q / W 分别播放入点前 / 出点后 500ms；E / D 分别播放选区开头 / 结尾最多 500ms，短选区不会向外扩展。
- 单次播放裁剪到视频边界，空交集不播放，不更改字幕时间。循环按钮沿用原有区间校验，两种模式共用一个播放观察器。
- 移除 I/O/J/K/U/P/L/N 的全局键盘绑定，按钮回调保留。分栏方向键、Home/End 和按钮原生 Space / Enter 激活保留。
- 继续过滤输入框、textarea、select、contenteditable、role=textbox、视频控件、IME、修饰键及长按重复；新增忽略已被其他处理器消费的事件。

## 已执行验证

- `npm run typecheck`、`npm run test -- --run`（4 个文件，52 项）、`npm run build`、`git diff --check` 通过。测试覆盖映射、移除的键、焦点 / IME 过滤、范围裁剪、短选区、单次停止、循环回绕、监听器清理和播放失败。
- 内嵌 Chromium，使用现有 310 秒合成视频和临时字幕。选区 1–3 秒：Q/W/E/D 分别从约 0.5/3/1/2.5 秒开始，在 1/3.5/1.5/3 秒暂停；S 和 Space 均从 1 秒开始并在 3 秒暂停。
- Q 在入点 0.1 秒时只播放 0–0.1 秒；W 在出点 309.9 秒时只播放到 310 秒视频结尾，均正常暂停。
- 原循环按钮仍能持续循环；从按钮焦点按 S 切换到单次模式后在出点暂停，循环状态关闭。
- 点击原 +10ms 按钮后按 G 正常提交；同一按钮焦点下 Enter 继续执行微调，移至空白区域后 Enter 提交。时间输入框内 Enter 不提交。
- 字幕 textarea 输入 `gsqwed ` 和 Enter 只编辑字幕，播放器保持暂停；旧 I/O/J/K/U/P/L/N 不改变时间、字幕行数或循环状态。

真实中文输入法组合输入仅有自动化事件过滤测试，本次未做人工输入法验收；原生 video 的播放边界观察仍依赖浏览器帧调度，不宣称音频采样级精度。

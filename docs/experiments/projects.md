## 明确限制

- 没有自动保存、实时推送/合并、行锁、审核/事件历史、恢复机制或样式库。项目存的是受支持 ASS DTO 的整文档快照，revision 不等同事件序号。
- 元数据和字幕共享 revision；其他管理操作可能要求已有编辑器先导出并重新加载。冲突保留本地输入，避免猜测合并或覆盖。
- 保存与导出只包含已应用时间。未保存字幕、未应用时间及 File 仍在页面内存，刷新/关闭会丢失；项目初始化或手动保存成功的快照可重新打开。
- 初始片源固定，不能在面板中换片或跨组织移动；摘要校验防误选，不是恶意客户端的真实性证明。
- 实际大型片源的哈希性能、Firefox/Safari、完整移动端制作、生产 HTTPS/部署和真实成员长期使用尚未验收。没有宣称这些通过。
- 当前本机 5173/8000 服务已接入项目路由；生产发布不在本任务范围。

# 打轴快捷键与 UI 回归

2026-10-22。范围仅为既有验证台的快捷键修复与界面调整，不新增持久化或协作能力。

## 原因与改动

点击 P 微调按钮后，浏览器正常保留按钮焦点；旧 `allowsShortcut` 将所有按钮目标排除，使后续 L 被拦截。新规则允许按钮焦点下的字母快捷键，不强制 blur；空格 / Enter 仍交给按钮、链接和展开项的原生激活。文本输入、选择框、可编辑区域、视频控件、修饰键和 IME 的过滤不变。

UI 遵循本仓库 `no-slop-ui`，沿用现有配色，移除阶段标签、副标题与装饰性图标；文件操作集中于顶栏，入出点并排，字幕表分列显示时间。字体设置、导入原件、快捷键说明及实验工具使用原生展开项。保留持续可见的未持久保存提示。实施初期 skill 引用的两个参考文件缺失；收尾时发现已补齐，已补读 `banned-patterns.md` 和 `colour-palettes.md` 核对。窄窗口保留入出点并排，避免把所有表单纵向堆叠；字幕表在自身区域滚动。

`TimePointControl` 只复用两个端点的展示及回调，区间校验和数据状态仍在 EditorWorkbench。未修改 ASS DTO、序列化、媒体传输或后端模块。

## 已执行

- `npm run typecheck`、`npm run test -- --run`（7 项）、`npm run build` 通过。
- 内嵌 Chromium，使用自有 6 秒 H.264/AAC 合成片：点击 `+10ms [P]`，读取到焦点仍在 P 按钮；直接按 L 后开始循环，再按 L 停止，无需点击空白处。
- 同一按钮焦点下，空格、Enter 分别继续微调出点且视频保持暂停；没有被全局播放 / 应用时间接管。
- 字幕文本框键入 L 只插入文本，循环保持关闭；IME 过滤保留单元测试，未宣称完成真实输入法人工试用。
- 本地字体预览、字幕定位、应用时间、ASS 导出和导入替换检查通过。重新解析浏览器导出稿，得到入点 1200ms、出点 1530ms 和预期中文 `\N` 换行。
- 桌面双栏及浏览器实际窄窗口均做目视检查；窄窗口宽度 503px，document scrollWidth 同为 503px，字幕表自身水平滚动，不造成页面横向溢出。页面控制台无 error / warn。

本轮未重做真实片源、长期制作或 Aegisub 渲染对照；这些限制仍见 [媒体 / ASS 记录](media-ass.md)。

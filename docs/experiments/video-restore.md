# 本机项目视频恢复

范围：项目工作区；普通本地工作区不恢复。视频不复制、不上传，服务端媒体基准和字幕保存契约不变。

执行计划：
1. 在 media 模块封装只读文件选择和 IndexedDB 句柄存储；按账号、组织、项目、SHA-256/大小关联。
2. 新建项目显式传递所选 File/句柄；工作区仅在有权限时自动读取，缺少授权时由点击请求授权。
3. 自动/手动共用完整 SHA-256 和播放器元数据校验；通过后才记住句柄。失败回到手动导入，取消/卸载/隐藏隔离旧任务。
4. 用真实浏览器和本地文件系统句柄验证跨刷新恢复、重新授权、文件变化、隔离与兼容回退；运行类型、单元和构建检查。

# ASS 兼容性第二、三阶段（2026-11-11）

依据：[第一阶段审计](../reviews/ass-compatibility-audit-2026-11-10.md)。长期支持契约仅维护于 `backend/ass_format/README.md`。

## 执行顺序与范围

1. 为 F1–F5 建立回归并在未修复实现上复现；增加自制完整文件、手写语义期望和非法输入矩阵。
2. 局部修改 `ass_format/codec.py` 与 `styles.py`：规范结构化脚本键、拒绝星号开头的样式名、ASCII 数字词法、逐事件样式引用定位与安全空白边界、导入预检最终输出预算。
3. 覆盖样式操作/模板、HTTP Import → Export → Import、PostgreSQL 项目创建/读取/保存/导出/再导入，以及前端严格 UTF-8 文件边界。用安装的 JASSUB WASM 检查关键解释差异。
4. 运行格式/HTTP/项目测试、前端检查、依赖扫描与 Diff 审查；更新模块契约及实际验证记录。

## 风险与决定

- 不改公共 DTO/API、数据库结构、保存/CAS、实时协议和 UI。保护性拒绝属于既有受限格式边界的纠错，不静默合并星号样式或改写无效数值。
- 名称与字体名称分开校验；星号限制只施加于 ASS 样式身份。
- ASCII 十进制（含符号、小数和指数）继续支持，先词法后 Decimal 范围校验，不接受 Python 下划线或 Unicode 数字。
- 导入复用现有完整序列化预检，避免复制输出预算算法；内部 `_inspect` 不调用 parse，保持无递归。
- Script Info 未结构化键仍原文保留，不在本任务中改变 Timer/WrapStyle/YCbCr Matrix 产品边界；保留不代表已验证解释。
- 本地空轴补行、剪贴板回退、字体替代、跨播放器视觉差异保留原有契约。

## 复核 R1–R3 补修（2026-11-11）

依据：[复核报告](../reviews/ass-compatibility-follow-up-2026-11-11.md)。当前实现/真实 WASM 已复现全部反例；R1/R2 导出改变图像，R3 往返图像相同但模型身份与引擎引用不同。

1. 为原始键/值/样式字段空白及 Default 大小写保留名增加失败回归、独立文件与手写错误位置，复用 HTTP/项目非法语料验证失败原子性。
2. `codec.py` 的语法空白只移除 ASCII 空格/Tab；样式 Name/Fontname 仅去安全的前导 ASCII 空白，尾部空白交给共享校验拒绝，数值字段只去前后 ASCII 空白。非 ASCII 文本/元数据不作全局禁止。
3. `styles.py` 拒绝 Default 的非规范大小写变体，不把普通样式名按大小写合并；操作/模板/直接导出共享最终校验。
4. 扩充 WASM 对照：拒绝反例的引擎解释证据、受影响时刻（2s、3.6s）、安全 ASCII 空白对照及所有有效轨道的模型 style_id → 引擎实际样式名一致性。完成相关测试、静态检查和文档同步。

保持公共契约、源行锚点、保存/revision 与依赖方向；不扩展 ASS 功能范围。

补修完成：新增原始词法/保留名回归、7 份非法语料、逐 Cue 引擎一致性检查；150 项后端测试（149 通过、1 跳过）、WASM 和 TypeScript 检查通过，详见同一验证记录的“复核 R1–R3 补修”。

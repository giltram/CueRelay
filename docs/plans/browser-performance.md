2. F2：以 F1 结果为基线评估可见行渲染；若搜索长任务仍存在，保留完整搜索/选择数据，验证 reveal、多选、菜单、QC、列宽和键盘焦点。
3. F5：播放/试听期间运行播放头 RAF；暂停、定位、视窗改变和恢复时离散刷新，隐藏后停止。避免相同值 DOM 写入。
4. F4：同一 Worker 的未变化分析 tile 在当前视窗中复用，不扩展缓存预算；验证模式升级、换片和取消。
5. F3：补测最后输入到有效预览以及取消浪费，再决定是否采用会话内串行 latest-only 转换；保持过期/错误保护。
6. F6：没有真实高规格片源及全进程内存数据，不调整媒体缓存预算，不推断泄漏。

逐项记录实际结果到 `docs/experiments/browser-performance.md`。性能脚本和原始数据保存在本次任务的可视化目录；功能回归保存在仓库。不得将 CPU 限速当作真实低端设备或 RAF 延迟当作 INP。

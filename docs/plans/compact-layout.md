# 紧凑顶栏与工作区布局

范围：删除项目选片提示；诊断导出仅放个人设置并精简说明；所有完整页面顶栏统一 44px；页面操作反馈显示在顶栏内；入点/出点/样式共用一行，缩短上方工作区，将空间交给字幕表。

实现：page-ui 只拥有页面壳和局部提示 portal 目标，不拥有业务消息。各模块保留现有状态/权限/保存契约；弹窗确认和校验保持 dialog 内。隐藏工作区使用自己的消息目标，避免污染当前页。

验证：类型检查、前端单元测试和构建；隔离 API 浏览器测试覆盖提示前后高度、编辑/保存、诊断下载、桌面/窄屏和保留工作区导航。结果完成后写入架构说明。

已完成：共享页面壳覆盖登录/初始化、列表、设置、路由状态与工作区；所有相关提示保留原状态所有权并进入所属顶栏。已完成回归及实际结果见 [布局验证](../experiments/compact-layout.md)。无未决实现约束。

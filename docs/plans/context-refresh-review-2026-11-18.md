# 会话上下文补充 review 修复

范围：组织响应之前打开本地工作区、持续重叠的组织读取、退出组织后慢个人设置阻塞列表、手动重试后旧错误残留。

实现约束：

- 本地链接的草稿组织范围来自 App 已知的路由/选择 ID，不等待组织对象；工作区仍按实例固定范围。
- 组织与个人设置各自按账号 epoch 和已完成请求版本接纳结果。较新请求尚未完成时，较早成功响应仍可推进；较新结果完成后，旧结果不能覆盖。退出组织/账号变更继续使旧 epoch 失效。
- 上下文错误按资源存储，成功只清理对应资源错误，不清理草稿操作等其他消息。
- 退出组织的操作与明确放弃的草稿处理完成后解除 busy，随后独立刷新上下文。

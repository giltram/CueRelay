## 边界与约束

- 成功路径走真实 API / PostgreSQL，不 fulfill 业务成功；故障注入只用于明确的失败保留检查并在场景中注明。
- Chromium context 可授权真实浏览器剪贴板；不代表外部应用交换、系统剪贴板权限或 OS 文件选择器验收。
- 使用 setInputFiles 的合成 MP4、真实哈希/Worker/codec；不代表真实片源、听感、字体观感、系统 picker/持久句柄权限。
- 不穷举快捷键/字段/筛选组合；冷却到期、并发、密码策略细节维持既有后端测试，不加 sleep/重试/skip。
- 无产品架构改变时不改架构文档；测试依赖仅向既有公开服务/HTTP，不引入产品依赖。

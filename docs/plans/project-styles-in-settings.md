# 项目样式入口迁移（2026-10-25）

用户要求：项目样式管理放到项目设置，移除项目工作区顶部入口。本地无项目设置，保留本地样式工具。

## 实施边界

- 复用 ProjectStyleManager 与现有 projectApi.styles，不改数据库、后端权限或 API。
- ProjectSettingsPage 持有一份 ProjectDetail 权威基准，元数据修改、样式操作与显式刷新共用 revision 和忙碌状态。名称/说明草稿独立保留，样式保存不覆盖它们。
- 样式操作使用设置页加载的已保存字幕快照，不读取/提交工作区内存或要求本地视频。其他打开的工作区保留旧文档/版本，后续保存须正常冲突，显式重载才能采用新样式。
- 保持权限：member 可管理活动项目样式；organizer/dev 管理元数据。所有成员可进入项目设置，归档样式只读。
- 移除工作区项目样式回调、app-workspace.styles 及其无用接口；工作区只提供单行样式分配与本地模式样式管理。
- 将已存在的纯 cue-order 下移为 subtitle-model 公共函数，供工作区和项目设置使用，避免 project-ui 依赖 workspace-ui 私有实现。

## 验证

- 样式保存与元数据保存连续使用正确 revision，未保存名称/说明保持。
- 原工作区未保存字幕/时间不被样式操作提交；旧工作区保存冲突且保留草稿，显式重载后更新。
- member 样式可编辑、元数据不可编辑；归档样式只读、会话失效禁写。
- 项目工作区无样式管理入口；本地入口保留；设置页复制/批量编辑/导入/预览/分配仍正常。
- 运行类型检查、单测、构建及相关浏览器回归，同步当前契约与模块文档。

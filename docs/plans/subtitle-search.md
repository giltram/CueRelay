# 字幕文本查找与定位

范围：仅前端工作区实例状态；不改契约、文档、保存、历史或服务端。

实现分工：
- `cue-search.ts`：从原始文本映射可见文本（只忽略支持的 b/i/u/s 0/1 标签，N/n/h 转义对应一个空格），返回原文高亮范围；复用 subtitle-model 时间排序，以 cue ID 导航。
- `use-cue-search.ts` / `CueSearchBar.tsx`：展开、关键词、当前命中、焦点与作用域快捷键；不写字幕状态。
- `CueTable`：保留所有行和原始正文，用 React 文本节点高亮；只有显式跳转滚动。
- `EditorWorkbench`：显式传入原有选行定位回调、工作区可见/弹窗可用性、返回焦点入口；主容器点击聚焦排除查找控件。

导航：关键词变更清空查找游标，首次从当前选行开始（包含选行）；之后按结果循环。尚未主动跳转显示 0 / N 行；当前 cue 不再匹配或被删除时恢复首次导航规则。空字符串不匹配；空格按普通字面文本匹配。不修剪关键词、不折叠连续空白。

验证：纯函数测试覆盖文本/排序/导航/数据变更；浏览器 fixture 覆盖草稿媒体无副作用、定位、焦点、IME、快捷键边界及只读；执行 TypeScript、构建、现有相关回归。实际运行结果记录在实验文档。

完成：实现、单元测试、Chrome 交互及现有字幕列表/焦点回归、TypeScript、构建、静态导入环检查和文档同步。具体执行结果与限制见 [验证记录](../experiments/subtitle-search.md)。

# 移除自定义显示名

2026-10-24，用户明确要求取消显示名设计，统一使用 username。

1. 删除 User.display_name，并通过增量 accounts.0003 RemoveField 升级；不改写已应用历史迁移。
2. 移除 Admin、密码相似性配置和 Session/成员/项目操作者 DTO 的显示名，前端统一 username，个人设置不再展示重复身份字段。
3. 更新测试/播种和当前架构/账号文档；补充迁移回归，验证账号 ID/密码、设置、会话和项目/成员关联保留。
4. 执行后端测试、前端单元/类型/构建及隔离浏览器回归。通过后按当前开发环境应用迁移、重启后端并核验。

边界：仅移除显示名及其数据，不修改用户名、认证方式、权限或字幕/媒体工作区所有权。部署前后端与迁移须一起发布。验证结果记录于 docs/experiments/username-only.md。

已完成全部步骤：62 项后端、187 项前端测试、类型/构建和 9 组真实用户系统浏览器回归通过。当前开发数据库已迁移、逐表核对其他数据保持一致，8000 后端已重启；生产发布不在本轮范围。

# 用户系统实施记录

范围：固定方案 A；账号、组织成员、个人快捷键、内存编辑保护。无项目持久化。

顺序：
1. PostgreSQL、自定义 User、Session/CSRF、四个业务实体与迁移。
2. 组织业务入口锁定目标用户，再锁定组织；账号停用由 application 协调，accounts 不反向依赖 organizations。Admin 使用相同入口，成员表只读。
3. 共享 JSON 声明默认键位；数据库仅存动作覆盖，覆盖替换该动作的全部默认绑定，空数组表示禁用。
4. App 编排登录/组织/设置，EditorWorkbench 暴露保护状态和导出接口；普通会话检查保持同一组件实例。
5. PostgreSQL 竞争测试、前后端回归、浏览器验证、同步文档。

初始检查：工作树干净；仓库没有业务数据库配置或迁移。音频实验依赖和实现保留。

完成：四个业务实体/首次迁移、Session/CSRF、固定组织权限、Admin 协调、个人快捷键、账号界面和本地编辑保护均已落地。App 显式拥有请求客户端实例，无模块级账号状态。所有文档已同步；实际验证和明确限制见 experiments/user-system.md。未进入项目持久化或音频后续工作。

字幕由文字、出现时间（入点）、消失时间（出点）和样式组成。“打轴”就是让这段时间贴合对白。如果你熟悉 Aegisub，可以直接跳转“Aegisub 用户速查”。

如果是第一次制作字幕，可以阅读下面的文字快速入门，或者在B站搜索aegisub教程。CueRelay的操作逻辑与aegisub较为相近。

## 做出第一条字幕 {#first-cue}

1. **准备视频。** 在项目列表点击项目名称，进入后选择项目指定的视频。出于技术和成本方面的考虑，视频不会上传，所以每次新开或刷新工作区都需要重新选择视频。如果提示视频不匹配，请向项目负责人索取相同片源。如果只是练习，用列表中的「本地工作区」，加载视频即可从空字幕开始。
2. **找到一句对白。** 用视频下方的播放按钮和进度条找到大致位置，再看右侧频谱。时间从左向右推进，有声音的位置通常较亮。
3. **定入点和出点。** 在音频区进行操作，在一句话开始处左键设置入点，在结束处右键设置出点。按 `S` 或 `空格` 试听这个区间，检查是否漏字或带入下一句。
4. **写文字，再应用时间。** 按 `Tab` 进入当前字幕文本框，输入对白；再按 `Tab` 回到打轴区域。按 `G` 或 `Enter` 应用当前入点、出点并选择下一行。末行提交后会自动新增空行，可以继续做下一句。
5. **回看并保存。** 在下方字幕表点击刚才那一行，视频会暂停并定位到它的入点。播放视频检查画面与字幕。项目点击「保存项目」写入服务器；本地工作区点击「导出 ASS」下载字幕文件。

> **记住两步：** G / Enter 是应用时间并换行，「保存项目」才是保存到服务器。未应用的时间输入不会包含在普通保存或导出中。文字和行样式的修改直接进入当前草稿，但也需要保存或导出才能保留。

## 听音、定时与输入 {#timing}

**调整边界：** 入点用左键拖动，出点用右键拖动。边界获得焦点后，用左右方向键微调，每次 10ms；按住 Shift 为 100ms。也可以直接改「入点」「出点」时间输入。出点必须晚于入点；改好后仍要按 G / Enter 应用。

**移动视野：** 普通滚轮平移音频时间轴，Shift + 滚轮以鼠标位置为中心缩放，也可拖动画布或底部横向滚动条。右侧竖直滑块调整频谱亮度 / 波形显示幅度，双击恢复；它不改变音量。

**区分试听与视频播放：** S / 空格只听当前选区，Q / W 检查边界外是否漏音，E / D 检查选区两端。音频试听时视频画面和字幕预览保持静止，这是正常行为。看完整画面用视频播放按钮；全屏时空格改为视频播放 / 暂停。

**输入文字时：** 字母和 Enter 用于输入，不执行普通打轴快捷键；Enter 换行会保存为 ASS 的 `\N`。用 Tab 回到打轴区后再提交。若 Tab 已在个人设置改为 Ctrl + 空格，请使用你的绑定；其他表单和 Shift + Tab 保持普通焦点导航。

**换行选择前先提交：** 点击字幕表会载入目标行的已应用时间，未应用的时间输入会被替换。「定位选中行」也按已应用的入点定位；预览能显示有效的时间草稿，不代表它已经保存。

「个人设置 → 音频显示」可切换频谱（Spectrum）或波形（Waveform），保存后回到工作区生效。波形和时间标尺的单击用于定位视频；上面的左右键点击定时针对频谱本体。个人设置关闭「鼠标点击设置字幕边界」后，频谱左击也变为定位视频，仍可拖动边界定时。

工作区内按 `Ctrl / Cmd + F` 查找字幕文字，Enter / Shift + Enter 跳到下一 / 上一条匹配行，Esc 收起查找。查找只定位，不替换文字。输入框中的撤销 / 重做由浏览器处理，打轴区中的撤销 / 重做恢复字幕编辑；本工作区最多保留 100 步，刷新后清空。

播放头裁剪与拆分默认没有快捷键，可在个人设置分别配置「设置入点为播放头」「设置出点为播放头」「在播放头位置拆分字幕」「在文本光标位置拆分字幕」。绑定冲突时先调整原动作，再保存快捷键。

## Aegisub 用户速查 {#aegisub}

| 熟悉的工作  | 在 CueRelay 中                                                         |
| ------ | -------------------------------------------------------------------- |
| 音频打轴   | 默认频谱左键设置入点、右键设置出点；G / Enter 应用并下一条，末尾自动续行。不要在文字输入焦点内按字母键打轴。          |
| 提交与保存  | 应用时间、保存项目、导出 ASS 是不同动作。没有自动保存；本地工作区只能通过导出保留文件。                       |
| 打开 ASS | 组织项目在新建时导入 ASS 或空字幕；只有本地工作区提供「导入 ASS」替换当前字幕。复杂特效 ASS 可能无法导入，见下文支持范围。 |
| 样式管理器  | 组织项目在「项目设置 → 项目样式 → 管理项目样式」编辑；工作区的样式下拉框只给当前行选择样式。本地工作区使用「管理样式」。      |
| 预览与字体  | 「显示字幕 / 隐藏字幕」控制视频叠字。浏览器使用应用提供的字体回退，不会自动读取本机字体，外观可能与桌面软件不同。           |

这里没有完整复刻 Aegisub 的菜单、自动化脚本和特效编辑。现有操作围绕基础打轴、文字与样式、ASS 交接展开。

## 保存与多人接力 {#saving}

**项目模式：** 「保存项目」保存当前已应用的字幕快照。其他成员不会实时看到你的编辑，需要重新加载才能看到已保存版本。重新加载会替换当前内存稿件，先导出要保留的修改。

**发生版本冲突：** 说明其他页面或成员已经保存了新版本。你的本地输入仍保留；先应用需要保留的时间并导出 ASS，再与负责人协调或重新加载最新项目，避免丢稿。不要期待重复点击保存能覆盖新版本。

**拆分的例外：** 项目中的拆分会立即保存整份当前字幕，并包含当前行显示的时间草稿。撤销拆分只恢复本地内容；需要再点「保存项目」才能把撤销结果保存到服务器。本地拆分仍需导出。

**标签页与刷新：** 项目名称、设置和手册默认在新标签页打开，各工作区独立，未保存内容不会跟着链接复制。刷新、关页会丢失内存稿件；本地工作区尤其要及时导出。同一页面的浏览器前进 / 后退可保留工作区，不能当作备份。

**账号或权限变化：** 会话失效时当前稿件保留，同账号重新登录可以继续。归档项目只能查看、导出；片源未校验、会话失效或失去访问权限时，编辑 / 保存会受限。若遇到异常，可在个人设置导出诊断信息交给维护者；它用于排查问题，不能恢复字幕。

## 样式与 ASS 导入 {#styles}

**样式如何生效：** 行编辑器里的「样式」决定当前行使用哪套外观。项目设置中的样式修改会立即写入服务器，使用的是已保存的字幕；请先保存工作区修改再去调整。已打开的工作区需重新加载项目才能采用新样式。组织模板是复制到项目的快照，之后修改模板不会自动改动项目。

**支持范围：** 导入接受 UTF-8 编码的基础 ASS（可带 BOM），最大 1MiB、5000 个事件。支持标准样式、中文、逗号、换行和空白转义，以及粗体 / 斜体 / 下划线 / 删除线标签。导出保留受支持的内容和格式语义，不保证与原文件逐字节相同。

**导入被拒绝时：** 绘图、动画、卡拉 OK、局部字体 / 颜色 / 定位标签、附件及其他不支持的字段或标签会让整份导入失败，不会只导入一半。保留原件，在 Aegisub 中另存一份符合支持范围的基础字幕后再导入；不要为了导入直接覆盖特效原稿。文本光标拆分还有更严格限制：含 ASS 标签或反斜杠转义（包括换行）的行暂不支持拆分。

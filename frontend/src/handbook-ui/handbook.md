字幕由文字、出现时间（入点）、消失时间（出点）和样式组成。“打轴”就是让这段时间贴合对白。如果你熟悉 Aegisub，可以直接跳转“Aegisub 用户速查”。

如果是第一次制作字幕，可以阅读下面的文字快速入门，或者在B站搜索 Aegisub 教程。CueRelay的操作逻辑与 Aegisub 较为相近。

## 做出第一条字幕 {#first-cue}

1. **准备视频。** 在项目列表点击项目名称，进入后选择项目指定的视频。出于成本方面的考虑，视频不会上传，所以每次新开或刷新工作区都需要重新选择视频。如果提示视频不匹配，请向项目负责人索取相同片源。如果只是练习，用列表中的「本地工作区」，加载视频即可从空字幕开始。
2. **找到一句对白。** 用视频下方的播放按钮和进度条找到大致位置，再看右侧频谱。时间从左向右推进，有声音的位置通常较亮。
3. **定入点和出点。** 在音频区进行操作，在一句话开始处左键设置入点，在结束处右键设置出点。按 `S` 或 `空格` 试听这个区间，检查是否漏字或带入下一句。可以此时按 `G` 或 `Enter` 应用当前入点、出点并选择下一行，也可以先写文字再应用，但是未应用的修改会在切换选中字幕的时候丢失。
4. **写文字。** 按 `Tab` 进入当前字幕文本框，输入对白；再按 `Tab` 回到打轴区域。按 `G` 或 `Enter` 应用当前入点、出点并选择下一行。末行提交后会自动新增空行，可以继续做下一句。
5. **回看并保存。** 在下方字幕表点击刚才那一行，视频会暂停并定位到它的入点。播放视频检查画面与字幕。项目点击「保存项目」写入服务器；本地工作区点击「导出 ASS」下载字幕文件。[TK 增加多人协作之后这一段需修改]

## 更详细的打轴设计 {#timing}

**调整边界：** 入点用左键拖动，出点用右键拖动。边界获得焦点后，用左右方向键微调，每次 10ms；按住 Shift 为 100ms。也可以直接改「入点」「出点」时间输入。出点必须晚于入点；改好后仍要按 G / Enter 应用。

鼠标点击定时或拖动边界时，距离其他字幕边界、当前行另一端或播放头不超过 8px，会自动吸附到最近的位置。按住 Shift 可临时取消吸附，时间仍保持 10ms 精度。吸附范围随音频视野缩放换算，不包含关键帧。

**调整音频区视野：** 普通滚轮平移音频时间轴，Shift + 滚轮以鼠标位置为中心缩放，也可拖动画布或底部横向滚动条。右侧竖直滑块调整频谱亮度 / 波形显示幅度，双击恢复。

**区分试听与视频播放：** `S` / `空格`只听当前选区，`Q` / `W` 检查边界外是否漏音，`E` / `D` 检查选区两端。出于技术方面的考虑，音频试听时视频画面和字幕预览保持静止。预览完整画面用视频左下角播放按钮。也支持全屏预览，全屏时空格可控制视频播放 / 暂停。

**输入文字时：** 字母和 `Enter` 用于输入，不执行普通打轴快捷键；`Enter` 换行会保存为 ASS 的 `\N`。用 `Tab` 可以切换打轴和输入文字的焦点。

**换行选择前先提交：** 点击字幕表会载入目标行的已应用时间，未应用的时间输入会被替换。「定位选中行」也按已应用的入点定位；预览能显示有效的时间草稿，不代表它已经保存。

「个人设置 → 音频显示」可切换频谱（Spectrum）或波形（Waveform），保存后回到工作区生效。波形和时间标尺的单击用于定位视频；上面的左右键点击定时针对频谱本体。个人设置关闭「鼠标点击设置字幕边界」后，频谱左击也变为定位视频，仍可拖动边界定时。

## Aegisub 用户快速上手 {#aegisub}

在项目列表点击项目名称，进入后选择项目指定的视频。出于成本方面的考虑，视频不会上传，所以每次新开窗口或刷新工作区都需要重新选择视频。如果提示视频不匹配，请向项目负责人索取相同片源。

**打轴**：操作方式和 Aegisub 近似 e.g. 左键设置入点、右键设置出点， `G` / `Enter` 应用。其余支持的快捷键见下表。

**样式管理**：组织项目在「项目设置 → 项目样式 → 管理项目样式」编辑；工作区的样式下拉框只给当前行选择样式。本地工作区使用「管理样式」。

暂时没有完整复刻 Aegisub 的菜单、自动化脚本和特效编辑。

**字幕行菜单：** 右键任意字幕行打开操作菜单；`Ctrl` / `Cmd` 单击可多选，`Shift` 单击按可见时间顺序连选。右键已选行保留整组选择且不定位视频；删除、剪切、复制、重复和帧分割作用于所选行。菜单也可通过行按钮上的 `Shift+F10` 打开，用方向键选择、`Esc` 关闭。列表继续按时间排列，前后插入的位置体现在文档和导出 ASS 的行顺序中。

普通插入为空正文、继承当前样式，默认 3 秒，按已有字幕最近边界缩短；没有有效时长时提示并保留原稿。按视频时间插入从当前帧开始持续 3 秒。帧前分割使后半段从当前帧开始，帧后分割使后半段从下一帧开始；两段保留完整正文。帧落在字幕区间外时只增加覆盖当前帧的副本。所有操作仍受非负 10ms 精度和正时长限制。

剪贴板使用 ASS Dialogue 文本，可与 Aegisub 互通，但仍受本项目的 ASS 子集限制。普通文本每个非空行粘贴为一条 0–3 秒字幕，沿用当前样式；未知样式使用当前样式。粘贴插入到当前行之前。粘贴覆盖默认只覆盖正文，可勾选入点、出点、样式；多选时按文档顺序对应所选行，单选时从当前行向下覆盖，多出的剪贴板行忽略。输入框内保留系统文字剪切、复制和粘贴。编辑可撤销，复制本身不增加撤销步骤。

## 样式与 ASS 导入 {#styles}

行编辑器里的「样式」决定当前行使用哪套外观。

**支持范围：** 导入接受 UTF-8 编码的基础 ASS（可带 BOM），最大 1MiB、5000 个事件。支持标准样式、中文、逗号、换行和空白转义，以及粗体 / 斜体 / 下划线 / 删除线标签。导出保留受支持的内容和格式语义，不保证与原文件逐字节相同。

**导入被拒绝时：** 绘图、动画、卡拉 OK、局部字体 / 颜色 / 定位标签、附件及其他不支持的字段或标签会让整份导入失败，不会只导入一半。保留原件，在 Aegisub 中另存一份符合支持范围的基础字幕后再导入；不要为了导入直接覆盖特效原稿。文本光标拆分还有更严格限制：含 ASS 标签或反斜杠转义（包括换行）的行暂不支持拆分。

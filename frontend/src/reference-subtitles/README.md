# Project reference comparison

Read-only presentation of project SRT references. Public UI: `ReferencePanel` accepts cues, the selected applied subtitle interval, the existing video node/current time, audition playing state/real position getter and visibility. It owns collapse, scroll and a leaf-only animation subscription. It never seeks media, mutates subtitles, or issues requests. No local-workspace support.

`matching.ts` owns stable start/end/source-order sorting, half-open interval/point overlap, all matches and one preceding/following context. Zero-length references match an exact playback point or a selected interval containing that point; empty bodies remain matches. Gaps return zero matches and nearest ended/upcoming context. `referenceContext` chooses real audio clock > running video > selected applied interval > current video position. Preparation/finish/error return to editing context; uncommitted timing inputs do not change the selected interval. No line-number pairing.

`ReferencePanel` renders plain React text nodes, supports native selection/copy and a single collapse action. The 112px scroll viewport keeps long blocks/multiple matches from moving the editor. On context or saved reference changes it reveals the first current match (or no-match notice), with up to 24px preceding context; it does not continuously reset user scroll inside the same group. There is no empty slot when reference is null. Reference controls/scroll focus are excluded from workspace timing/search shortcuts and background focus capture. The collapse mouse action preserves the existing input focus.

Dependencies: `{workspace-ui} → reference-subtitles → {contracts, i18n, React, browser read APIs}`. Matching depends only on contracts. Backend parsing/ownership: `srt_format` and `projects/reference_services.py`; transport: `project-data`; request identity/order: `app-workspace`. Existing project observations adopt only reference/status/permissions, never document/revision. Equal reference versions retain the same cue array through status polls, preserving manual scroll/native text selection. Reference visibility additionally requires current project read access (`mediaOwnerId`). Project/identity instance replacement and read-denial fences are upstream responsibilities.

Tests: `matching.test.ts`, `project-data/subtitle-api.test.ts`, `frontend/regression/reference-subtitles.spec.mjs` through three explicit Django `test_reference_*` entries. Deployment, full API and actual validation: `docs/plans/project-reference-subtitles.md`.
